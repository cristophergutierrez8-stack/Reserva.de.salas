# Database Skill

## Entidades mínimas
Usuario/Perfil, Sala, Reserva y Auditoría.

## Integridad
Evitar duplicidad de reserva de una sala en el mismo horario. Las reglas complejas deben reforzarse en lógica de negocio/transacciones.

## Migraciones
Toda modificación de modelos debe tener migración.

## Datos
Usar únicamente datos ficticios de desarrollo. No incluir datos personales reales.
