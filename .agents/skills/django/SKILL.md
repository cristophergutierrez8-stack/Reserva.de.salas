# Django Skill

Implementar backend con Django 4.2.x, Django Auth, ORM, formularios y autorización por rol.

## Reserva
Validar usuario, bloqueo, sala activa, disponibilidad, capacidad, máximo diario, simultaneidad, consecutividad e integridad de fecha/hora.

## No-Show
Solo roles autorizados. La reserva debe existir, estar confirmada, haber terminado y no estar cancelada ni marcada previamente. Registrar fecha y aplicar bloqueo.

## Seguridad
CSRF, ORM, validación, autorización, sesiones seguras y manejo seguro de errores. Secretos fuera del repositorio.
