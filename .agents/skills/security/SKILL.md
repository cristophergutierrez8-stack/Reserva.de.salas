# Security Skill

Aplicar seguridad desde el diseño.

Controles: autenticación, autorización por rol, CSRF, validación, sesiones, contraseñas seguras, variables de entorno, protección de datos, auditoría y manejo seguro de errores.

Revisar especialmente controles OWASP relacionados con control de acceso, inyección, autenticación, configuración y exposición de información.

Una validación visual en frontend nunca sustituye una validación del backend.
