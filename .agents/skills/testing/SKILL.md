# Testing Skill

Mantener trazabilidad entre requisitos y pruebas.

## Niveles
Unitarias, integración, funcionales, seguridad y validación manual de interfaz.

## Casos críticos
Autenticación, permisos, disponibilidad, capacidad, máximo 2/día, consecutividad, conflicto, cancelación 24h, reserva asistida, No-Show y bloqueo.

## Regla
Nunca afirmar PASS sin ejecución real.

## Registro
Cada caso debe tener ID, requisito, precondiciones, pasos, esperado, obtenido, estado y evidencia.
