# UML Skill

Mantener diagramas coherentes con el prototipo real.

## Diagramas
Casos de uso, actividad, secuencia, clases, estados, componentes y despliegue.

## Regla
No dibujar comportamiento que el código no implemente.

## No-Show
La Reserva tiene estado NO-SHOW. El Usuario tiene una restricción temporal de bloqueo. No mezclar ambos conceptos.

## Revisión final
Comparar UML contra modelos, vistas, servicios, permisos y flujos reales.
